# Backlog Gamer

Aplicativo desktop para catalogar uma coleção de jogos e acompanhar quais já foram zerados.


## Sobre o projeto

O Backlog Gamer permite cadastrar jogos, consultar a lista completa em uma tabela e excluir registros. Os dados são salvos em disco, em arquivo serializado, e carregados novamente quando o app é aberto.

## Tecnologias

- C#
- Visual Studio 2026
- Windows Forms (.NET Framework)
- Serialização em JSON.
